# EraTranslator

Emuera 게임의 `ERB`, `ERH`, `ERA`, `CSV`, `CVS` 파일을 스캔해 번역 가능한 텍스트를 추출하고, 번역 진행 상태를 관리하며, 결과물을 게임 폴더에 다시 적용할 수 있도록 돕는 WPF 번역 보조 도구입니다.

## 실행 요구 사항

- Windows 환경에서 실행합니다.
- `.NET 8 Desktop Runtime`이 필요합니다.
- 설치되어 있지 않다면 Microsoft 공식 [.NET 8 다운로드 페이지](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)에서 `Run apps - Runtime` 섹션의 `.NET Desktop Runtime 8` Windows 버전을 설치하세요.
- 앱을 직접 빌드하려면 `.NET 8 SDK`가 필요합니다.

## 주요 기능

### 추출과 스캔

- 게임 폴더를 선택하면 `ERB`, `ERH`, `ERA`, `CSV`, `CVS` 파일에서 번역 대상 문자열을 추출합니다.
- Emuera 스크립트의 명령문, 주석, 문자열, CSV 컬럼 규칙을 구분해 번역이 필요한 항목만 모읍니다.
- `ERH`의 `#DIM`, `#DIMS` 선언 문자열도 번역 대상으로 추출합니다.
- 코드와 텍스트가 섞인 ERB에서는 재사용 가능한 라벨 span을 안정적으로 추출하고, 대사형 문장은 문장 단위로 유지합니다.
- 대규모 프로젝트에서도 병렬 스캔과 캐시 저장 최적화로 UI 응답성을 유지합니다.
- 이미 번역된 출력물이나 재추출된 프로젝트에서도 기존 번역 진행 상태를 최대한 이어받습니다.

### 번역 작업

- OpenAI 호환 API, LM Studio, DeepL, Papago, EzTransXP 번역을 지원합니다.
- LM Studio는 `json_schema` structured output 우선, 보수적 재시도, tokenized fallback 순서로 동작해 로컬 모델의 JSON 안정성을 높입니다.
- Gemma 4, Qwen 3.5 9B 같은 LM Studio 로컬 모델에 맞춘 샘플링 프리셋과 thinking 제어를 지원합니다.
- 자동 번역, 수동 수정, 번역 제외, 검증 상태를 항목별로 관리합니다.
- 같은 원문을 가진 항목은 수동 수정 내용을 함께 전파해 반복 문구를 일관되게 유지합니다.
- 필터 범위에서 번역해도 같은 원문의 기존 완료 번역을 우선 재사용하고, 필터 밖 미번역 동일 원문에도 결과를 전파합니다.
- 자동 번역은 현재 범위 안에서 `CSV -> ERH -> ERB` 순서로 단계 실행하며, 앞 단계 번역에서 얻은 glossary 힌트를 다음 단계에 재사용합니다.
- 하단 편집기와 그리드 직접 편집을 통해 번역문을 수정할 수 있습니다.

### Emuera 문법 보호

- `%...%`, `{...}`, `<...>`, `\@...\@`, 선택지 표기, 줄바꿈, 이스케이프 문자를 보호합니다.
- 사용자 사전 창의 `보호 문자` 탭에서 보호할 전각 특수문자 목록을 수정할 수 있습니다.
- 함수 호출이나 표현식 내부의 잘못된 구분자, 조사 처리 대상 표현을 찾아 교정할 수 있습니다.
- 일반 한국어 문장에서도 `은/는`, `이/가`, `을/를`, `으로/로` 같은 조사를 앞 단어 받침에 맞춰 보정합니다.
- 번역 결과에서 플레이스홀더, 참조 기호, 제어 문자가 깨졌는지 검사하고 경고합니다.
- OpenAI 호환 프롬프트에는 현재 배치와 실제로 겹치는 glossary 힌트만 짧게 주입해 용어 일관성을 높입니다.

### 저장과 복원

- SQLite 기반으로 스캔 결과, 번역문, 상태, 검증 결과를 저장합니다.
- 앱을 다시 실행해도 이전 작업 상태를 복원합니다.
- 단건 수정은 빠르게 저장하고, 대량 변경은 배치 저장으로 처리해 반응성과 안정성을 함께 확보합니다.

### 필터와 검토

- 원문, 번역문, 파일 경로, 상태, 검증 결과 기준으로 항목을 필터링할 수 있습니다.
- 참조가 포함된 항목, 함수 또는 표현식 내부에 쓰인 번역문, 제외된 항목 등을 따로 확인할 수 있습니다.
- 조사 처리와 함수 교정 기능을 버튼으로 실행해 번역 후 흔한 오류를 빠르게 정리할 수 있습니다.

### 출력과 적용

- 번역 결과를 별도 출력 폴더에 저장하거나 원본 폴더에 백업 후 덮어쓸 수 있습니다.
- CSV 심볼명이 번역으로 변경된 경우, ERB 내부 참조를 원문 기준으로 찾아 저장 시 자동 재작성합니다.
- 재추출 후에도 참조 정보를 다시 연결해 기존 번역과 출력 안정성을 유지합니다.

## 권장 작업 순서

1. 게임 폴더를 선택합니다.
2. 필요하면 저장 모드를 고릅니다.
   - `별도 출력 폴더`: 원본은 그대로 두고 지정한 출력 폴더에 번역본을 만듭니다.
   - `원본 덮어쓰기 + 백업`: 원본 폴더에 직접 적용하되, 기존 파일을 백업합니다.
3. 처음 작업하는 폴더라면 `텍스트 추출`을 눌러 번역 대상을 가져옵니다.
4. 번역 공급자와 옵션을 바꿔야 한다면 `번역 설정...`을 먼저 확인합니다.
5. `번역 시작`으로 자동 번역을 실행합니다.
   - 내부적으로는 현재 범위에서 `CSV -> ERH -> ERB` 순서로 처리됩니다.
   - `ERH`는 `CSV` glossary를, `ERB`는 `CSV + ERH` glossary를 힌트로 재사용합니다.
6. 필터, 경고, 상태 컬럼을 보면서 문제가 있는 항목을 수동 수정하거나 제외 처리합니다.
7. 번역 후 `조사처리`와 `함수 교정`을 실행해 흔한 Emuera 문법 오류를 정리합니다.
8. 필요한 경우 `전역 치환...`, `텍스트 내보내기`, `텍스트 가져오기`로 대량 수정합니다.
9. 최종 검토 후 `결과 저장`을 눌러 번역 결과를 파일로 씁니다.
10. 게임 실행 로그에 오류가 있으면 해당 파일과 줄을 확인하고 다시 수정한 뒤 `결과 저장`을 반복합니다.

## 버튼 설명

### 프로젝트와 출력

- `찾아보기`: 게임 폴더 또는 별도 출력 폴더를 선택합니다.
- `저장 모드`: 결과 저장 방식을 선택합니다. 안전하게 확인하려면 먼저 `별도 출력 폴더`를 권장합니다.

### 작업 버튼

- `텍스트 추출`: 선택한 게임 폴더에서 번역 가능한 텍스트를 다시 스캔합니다. 기존 진행 상태는 가능한 범위에서 이어받습니다.
- `인코딩 변환`: 파일 인코딩을 변환합니다. 인코딩 문제로 원문이 깨질 때 사용합니다.
- `번역 시작`: 현재 추출된 항목을 설정된 번역 공급자로 자동 번역합니다.
- `결과 저장`: 현재 번역문을 파일에 적용합니다. 저장 시 CSV 심볼명 변경에 따른 ERB 참조도 함께 재작성합니다.
- `텍스트 내보내기`: 현재 번역 항목을 외부 편집용 텍스트로 내보냅니다.
- `텍스트 가져오기`: 외부에서 수정한 텍스트를 다시 가져와 번역문에 반영합니다.
- `번역 리셋`: 번역문과 번역 진행 상태를 초기화합니다.
- `추출 리셋`: 스캔 결과와 진행 상태를 초기화해 처음부터 다시 추출할 수 있게 합니다.
- `중지`: 진행 중인 번역이나 긴 작업을 중단합니다.
- `번역 설정...`: OpenAI 호환 API, LM Studio, DeepL, Papago, EzTransXP 같은 번역 공급자와 옵션을 설정합니다.
- `번역 설정...`의 LM Studio 섹션에서는 `자동`, `Gemma 4`, `Qwen 3.5 9B` 프리셋을 고르고 샘플링 값을 적용하거나 탭별 기본값으로 재설정할 수 있습니다.
- `사용자 사전...`: 번역에 반영할 사용자 사전 항목과 전각 보호 문자 목록을 관리합니다.

### 필터와 검토 버튼

- `전역 치환...`: 조건에 맞는 번역문을 한 번에 찾아 바꿉니다.
- `정규식`: 필터 입력값을 일반 텍스트가 아니라 정규식으로 해석합니다.
- `경고만 보기`: 플레이스홀더, 참조, 제어 문자 등 검증 경고가 있는 항목만 표시합니다.
- `실시간 갱신`: 번역문을 수정할 때 현재 필터 결과를 즉시 다시 계산합니다. 대량 검토 중 그리드 위치를 유지하고 싶으면 끄는 편이 편합니다.
- `갱신`: 현재 필터 조건을 다시 적용해 목록을 새로 고칩니다.
- `조사처리`: 번역문 안의 한국어 조사 후보를 문맥에 맞게 정리합니다.
- `함수 교정`: 함수 호출이나 `{...}` 표현식 안에서 일본어 쉼표 `、`가 인자 구분자로 들어간 경우 등 문법 오류 가능성이 높은 부분을 교정합니다.
